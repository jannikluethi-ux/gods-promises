Privacy

His Promise Daily is run by Jannik Luethi. Questions about privacy: Email Jannik Luethi (jannik.luethi@proton.me).

What stays in your browser

The site has no server-side accounts and no database. If you create a profile, your email address, optional display name, a salted password hash (PBKDF2), your sign-in session and your saved verses are stored in your browser’s local storage on this device, separately for each web address (the old GitHub address and hispromisedaily.com do not share them). Your chosen Bible version is stored there too, and verse texts from other versions may be cached for the current browser session. The site’s code does not send this information to the operator.

To delete it, sign out and clear this site’s data in your browser settings. There is no in-site account deletion yet, and the operator cannot recover or delete data that exists only in your browser. If you email us, we receive your email address and whatever you write.

Services your browser contacts

These providers handle data under their own policies, which we do not control.

  • Hosting – Vercel (hispromisedaily.com): the main address is served by Vercel Inc. Like any web host, Vercel receives technical request data such as your IP address, and location derived from it, when your browser loads the site. Vercel Privacy Policy
  • Hosting – GitHub Pages (old address, jannikluethi-ux.github.io): GitHub states that when a GitHub Pages site is visited, the visitor’s IP address is logged and stored for security purposes. GitHub Pages data collection · GitHub Privacy Statement
  • Fonts – Google Fonts: your browser requests fonts from fonts.googleapis.com and fonts.gstatic.com. Google states these requests include your IP address, the requested URL and HTTP headers such as your browser’s user agent and the referring page, that the Fonts API does not set or log cookies, and that this data is not used to build profiles or for targeted advertising. Google Fonts privacy FAQ
  • Bible versions – bible-api.com: only if you choose a version other than the World English Bible, your browser requests that verse text from bible-api.com (run by Tim Morgan). The request contains the verse reference and translation, and like any web request it reveals your IP address and may include our site address as the referrer. Your search words are not part of these requests. The service says it rate-limits by IP address; we could not find a privacy policy for it. bible-api.com
  • Support payments – Stripe: the “Support in USD” link opens Stripe’s hosted checkout. Nothing goes to Stripe unless you follow that link. Stripe’s policy says it may collect information entered into a checkout form even if you don’t complete it, and that it may transfer personal data to other countries, including the United States and India. Stripe Privacy Policy

Visitor statistics

On hispromisedaily.com only, the site uses Vercel Web Analytics to count page views and estimate how many visitors it has. These are anonymous estimates, not counts of confirmed people. It is not loaded on the old GitHub address or on preview addresses.

Before anything is sent, the site removes every query string and “#” fragment from the address and only reports its own known pages. Search words, sign-in redirect values, email addresses, profiles and saved verses are never sent, and no custom events are recorded.

Vercel states that Web Analytics uses no third-party cookies; visitors are recognised by a hash created from the incoming request, which is discarded after 24 hours. Each page view may be stored with a timestamp, the page address, the referring site, location (country, region, city), operating system and browser with versions, device type and the script version. Vercel’s privacy notice also says it collects information about traffic to its customers’ websites, such as visitor IP address and location derived from it. Vercel Web Analytics privacy · Vercel Privacy Notice

Cookies and other tracking

This site’s own code sets no cookies and includes no advertising, session-replay or other tracking scripts. The third-party services above may process data as described in their own policies.
