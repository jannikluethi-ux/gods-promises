   File:    reauthentication.html

Templates use these Supabase variables:
  {{ .ConfirmationURL }}  — action button and plain fallback link
  {{ .Email }}            — available, not shown in the body
  {{ .SiteURL }}          — available; footer and wordmark link to https://hispromisedaily.com
  {{ .NewEmail }}         — change-email.html only
  {{ .Token }}            — reauthentication.html (the confirmation code)
  {{ .Data.display_name }} — used in the greeting when present

Greeting / display_name
  js/auth.js signUp() writes user_metadata.display_name via
  options.data = { display_name }. Supabase exposes that as {{ .Data.display_name }}.
  Templates fall back to “Hello,” or “Welcome to His Promise Daily.” when it is empty.
  updateProfile() saves a later name change only to public.profiles, not to
  user_metadata, so later emails may still use the name from signup.
